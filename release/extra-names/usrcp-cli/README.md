# usrcp-cli

🚧 **Reserved — under development.** This name is held for the standalone USRCP command-line tool, which is on the [USRCP](https://github.com/frank-bot07/usrcp) roadmap.

**For the USRCP CLI today**, install the umbrella package or the core directly:

```bash
npm install -g usrcp        # umbrella (recommended)
# or
npm install -g usrcp-local  # core CLI + encrypted ledger
```

Watch the repo for updates: https://github.com/frank-bot07/usrcp
