# usrkey

🚧 **Reserved — under development.** This name is held for **USRKey**: portable, user-held encrypted context for AI tools — the user-facing product layer of the [USRCP protocol](https://github.com/frank-bot07/usrcp).

*Your context is yours. Carry the key.* See the [manifesto](https://github.com/frank-bot07/usrcp/blob/main/MANIFESTO.md).

**For the working implementation today**, use:

```bash
npm install usrcp-local
# or
brew install frank-bot07/usrcp/usrcp
```

Watch the repo for updates: https://github.com/frank-bot07/usrcp
